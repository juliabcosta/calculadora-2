Contexto

A interface está pronta. Falta implementar o comportamento.

Você trabalhará como desenvolvedor responsável pela lógica de uma calculadora simples. O HTML e o CSS já foram concluídos.

Desafio

Implemente somente script.js para permitir que o usuário digite números pelos botões, escolha uma operação, veja o visor mudar a cada clique, calcule com = e reinicie com C.

Você vai usar
  • querySelector() e querySelectorAll();
  • addEventListener('click', ...);
  • textContent para ler os botões;
  • textContent para atualizar o visor;
  • variáveis para guardar primeiro número e operação;
  • condicionais para decidir qual cálculo executar;
  • classList para o feedback visual.
Sequência sugerida
  1. Faça os números aparecerem no visor.
  2. Faça o visor juntar os dígitos: 1 → 12 → 123.
  3. Implemente a escolha da operação.
  4. Faça o segundo número iniciar uma nova digitação.
  5. Implemente o botão =.
  6. Implemente o botão C.
  7. Trate divisão por zero.
Entregável

Pasta da atividade com o arquivo script.js implementado.

Importante: trabalhe somente com números inteiros e uma operação por vez. Isso é suficiente para concluir a atividade.
